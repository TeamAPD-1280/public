# Simulations and Competitions

This page collects hands-on cybersecurity practice resources, including individual learning platforms, team-based competitions, and group-friendly training activities.

Capture the Flag (CTF) challenges, wargames, vulnerable labs, and tabletop exercises are useful ways to build practical skills in a safe and structured environment. Learners can use these resources independently, while clubs, classes, and teams can use them for workshops, practice sessions, and competitions.

## Choosing the Right Resource

| Resource | Best For | Format |
|---|---|---|
| [picoCTF](https://picoctf.org/) | Beginners, classrooms, clubs, and structured CTF practice | Individual or team CTF challenges |
| [TryHackMe](https://tryhackme.com/) | Guided learning and hands-on labs | Individual learning paths and rooms |

| [VulnHub](https://www.vulnhub.com/) | Vulnerable VM practice | Individual or group lab environment |

## Individual Practice Platforms

These resources are well suited for learners who want to practice independently and build skills at their own pace.

### picoCTF

Developed by Carnegie Mellon University, picoCTF is a free, beginner-friendly Capture the Flag platform designed for people learning cybersecurity. It provides progressively difficult puzzles across topics such as cryptography, reverse engineering, web security, forensics, and binary exploitation.

picoCTF can also be used by instructors, clubs, and teams, but it is especially useful for individuals getting started with CTFs.

[Try picoCTF](https://picoctf.org)

#### Skills and Tools

**Beginner**

- Basic programming and Linux terminal usage.
- Tools: Python and basic command-line utilities.

**Intermediate**

- Web security, cryptography, and reverse engineering.
- Tools: GDB, CyberChef, and Hashcat.

**Advanced**

- Binary exploitation, advanced forensics, and custom script development.
- Tools: Ghidra, Wireshark, and Burp Suite.

### TryHackMe

TryHackMe is an interactive online platform offering guided tutorials, virtual labs, and challenges that teach cybersecurity concepts from beginner to advanced levels. It covers topics such as penetration testing, networking, digital forensics, Linux, and web application security.

TryHackMe is a good option for learners who prefer structured walkthroughs and guided learning paths.

[Visit TryHackMe](https://tryhackme.com)

#### Skills and Tools

**Beginner**

- Basic networking, Linux fundamentals, and cybersecurity essentials.
- Tools: Nmap, Netcat, and basic command-line utilities.

**Intermediate**

- Web application security, cryptography, and privilege escalation.
- Tools: Burp Suite, John the Ripper, and Gobuster.

**Advanced**

- Active Directory exploitation, reverse engineering, and advanced penetration testing.
- Tools: Metasploit, BloodHound, and Wireshark.

### Hack The Box

Hack The Box is an interactive platform offering practical penetration testing labs, machines, and challenges. It provides realistic environments for learning web exploitation, privilege escalation, reverse engineering, digital forensics, and Active Directory attacks.

Hack The Box is useful for hands-on learners who want to sharpen practical skills or prepare for cybersecurity certifications.

[Visit Hack The Box](https://www.hackthebox.com)

#### Skills and Tools

**Beginner**

- Linux basics, networking fundamentals, and file handling.
- Tools: Nmap, Netcat, and basic Burp Suite.

**Intermediate**

- Web exploitation, including XSS and SQL injection, privilege escalation, and password cracking.
- Tools: Gobuster, SQLmap, and John the Ripper.

**Advanced**

- Binary exploitation, Active Directory attacks, and post-exploitation techniques.
- Tools: Metasploit, BloodHound, and Mimikatz.

### OverTheWire

OverTheWire is a hands-on wargame platform that teaches foundational cybersecurity concepts through progressive challenges. It is especially useful for learning Linux command-line usage, file permissions, networking, cryptography, and basic exploitation techniques.

OverTheWire is a strong starting point for learners who want to build problem-solving skills before moving into larger CTFs or penetration testing labs.

[Visit OverTheWire](https://overthewire.org/wargames/)

#### Skills and Tools

**Beginner**

- Linux fundamentals, shell navigation, file permissions, and basic networking.
- Tools: SSH, Netcat, and command-line utilities.

**Intermediate**

- Web application basics, cryptography, and privilege escalation concepts.
- Tools: Burp Suite, John the Ripper, and Gobuster.

**Advanced**

- Exploitation techniques, reverse engineering, and advanced Linux concepts.
- Tools: GDB, Wireshark, and scripting tools.

### Root-Me

Root-Me provides a wide range of cybersecurity challenges and CTF-style exercises. It includes topics such as web security, cryptography, forensics, network security, and reverse engineering.

Website: [root-me.org](https://www.root-me.org)

### WebGoat

WebGoat is a deliberately insecure web application maintained by OWASP. It provides hands-on experience with common web security issues and is useful for learning web application testing in a controlled environment.

Website: [OWASP WebGoat](https://owasp.org/www-project-webgoat/)

### VulnHub

VulnHub provides vulnerable virtual machines that can be downloaded and tested in a local lab environment. It is useful for learners who want to practice penetration testing methodology, enumeration, exploitation, and privilege escalation.

Website: [vulnhub.com](https://www.vulnhub.com)

### Cybrary

Cybrary offers cybersecurity training, certifications, and practice labs. It is useful for learners who want guided training alongside hands-on exercises.

Website: [cybrary.it](https://www.cybrary.it)

## Team Competitions and Group Activities

These resources are better suited for clubs, classes, security teams, or groups that want to practice together.

### CTFtime

CTFtime is a directory for Capture the Flag competitions. It lists ongoing and upcoming CTF events where individuals or teams can compete in cybersecurity challenges.

Use CTFtime to find public competitions, track event dates, and identify beginner-friendly or advanced team competitions.

[Browse upcoming competitions](https://ctftime.org)

### Backdoors & Breaches

Backdoors & Breaches is a cybersecurity tabletop card game designed to help teams practice incident response. It includes realistic cyberattack scenarios, procedures, and defensive actions that encourage collaboration, discussion, and decision-making.

This is especially useful for group training, security awareness workshops, and incident response practice.

[Learn about Backdoors & Breaches](https://www.blackhillsinfosec.com/projects/backdoorsandbreaches/)

[Play the online version](https://play.backdoorsandbreaches.com)

### picoCTF for Groups

Although picoCTF is useful for individuals, it can also work well for groups, classrooms, and clubs. Teams can use picoCTF challenges during workshops, beginner training sessions, or informal competitions.

#### Suggested Group Use

- Run a beginner workshop using selected picoCTF challenges.
- Split participants into small groups and assign challenge categories.
- Use easier challenges to teach basic Linux, Python, cryptography, forensics, and web concepts.
- Encourage participants to explain their solve process after completing a challenge.

[Try picoCTF](https://picoctf.org)

### Hack The Box for Teams

Hack The Box can be used for group practice when learners are ready for more realistic penetration testing scenarios. Teams can work together on machines, share enumeration strategies, and compare approaches.

#### Suggested Group Use

- Assign one machine or challenge to a small group.
- Have participants document enumeration, exploitation, and privilege escalation steps.
- Review lessons learned after each session.
- Use retired or beginner-friendly boxes for training sessions.

[Visit Hack The Box](https://www.hackthebox.com)

### TryHackMe for Groups

TryHackMe can support group learning through guided rooms and learning paths. It is helpful for structured workshops because many rooms provide explanations, tasks, and validation steps.

#### Suggested Group Use

- Select one room for a workshop or weekly training session.
- Pair beginners with more experienced participants.
- Use guided rooms for fundamentals and challenge rooms for practice.
- Debrief key commands, tools, and concepts at the end.

[Visit TryHackMe](https://tryhackme.com)

## Suggested Learning Path

### Beginner

Start with:

- OverTheWire Bandit for Linux fundamentals.
- picoCTF beginner challenges.
- TryHackMe introductory rooms.

Focus on:

- Linux command line.
- Basic networking.
- Python basics.
- Web security fundamentals.
- Cryptography basics.

### Intermediate

Move to:

- TryHackMe learning paths.
- Hack The Box starting-point machines.
- WebGoat.
- Root-Me challenges.

Focus on:

- Enumeration.
- Web application testing.
- Privilege escalation.
- Password cracking.
- Forensics basics.

### Advanced

Practice with:

- Hack The Box machines and challenges.
- VulnHub virtual machines.
- Public CTF competitions listed on CTFtime.
- Advanced picoCTF and Root-Me categories.

Focus on:

- Active Directory attacks.
- Binary exploitation.
- Reverse engineering.
- Advanced web exploitation.
- Post-exploitation techniques.

## Notes for Safe and Responsible Practice

Only use these tools and techniques in approved lab environments, official challenge platforms, or systems where you have explicit permission to test. Do not scan, attack, or attempt to exploit university systems, public systems, or third-party services unless you are authorized to do so.
